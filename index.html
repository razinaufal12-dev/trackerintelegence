Cara menghubungkan
  1. Unggah file Excel ke Google Drive, buka dengan Google Sheets, lalu pilih File → Simpan sebagai Google Spreadsheet. File .xlsx biasa tidak bisa dibaca.
  2. Klik Bagikan, ubah akses umum menjadi Siapa saja yang memiliki link: Pelihat.
  3. Tempel link Sheet di kolom atas dan klik Hubungkan. Nama tab harus sama dengan tab ringkasan di Sheet (bawaan: Ringkasan).
  4. Halaman ini hanya membaca. Mengisi data tetap dilakukan di Google Sheets, dan tampilan diperbarui otomatis tiap 60 detik.
